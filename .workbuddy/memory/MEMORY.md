# 项目长期约定：张安泽视频 / 主动学习成长工作台

## 代码现状（2026-11-12 起）
- `ipad-design/` 是当前唯一在迭代的版本（4:3 画板 + `store.js` 数据层）。根目录 `frontend/index.html`（1.6MB 单文件）与那一堆 `build_*.py` 是上一轮遗留，不要再往里加东西。
- **所有页面数值必须走 `store.js`，禁止在 HTML 里写死数字**。这是 2026-11-12 之前最大的问题（同一个灵石在 3 个页面 3 个值）。
- 新页面结构照抄 `play.html` / `pet.html`：`.stage` 1366×1024 + `transform:scale` 适配，元素 `position:absolute`，直接引 `store.js`。
- 注意 `.stage *{position:absolute}` 这个全局规则 —— **任何需要文档流的内联元素（`b`/`i`/`small`/卡片内的 flex 子元素）都必须显式 `position:static`**，否则会竖排或重叠。栽过两次。
- 卡片内的子元素坐标是相对卡片算的，不是相对 stage。写坐标前先确认定位上下文。
- 验证方式：`http.server` 必须 `run_in_background` 起；截图用 `puppeteer-core` 驱动系统 Chrome（Chrome 自带 `--screenshot` 在这台机器上是坏的）。
- **弹窗统一用 `Store.modal({icon,badge,tone,title,desc,ok,cancel,onOk})`**，不要用原生 `alert/prompt/confirm`。它注入 `.sm-*` 样式并挂在 `.stage` 内，跟随缩放。
- **商城/背包共用一套分类：道具 / 装备 / 服装 / 宠物**（商城多一个「全部」）。商品定义在 `store.js` 的 `ITEMS`，库存统一放 `state.inventory`，不要在页面里另存。
- 渲染列表绑事件时**别在 `for` 里用 `var` 捕获循环变量**（会全部指向最后一个），用 IIFE 或 `forEach`。已经在 bag 页栽过一次。

## 产品初心（不要偏离）
私有化、给自家孩子用的 iPad 学习产品：**优质名师视频课程（学而思、乐读、清华帅爸、科普）+ 游戏化激励（日历打卡、顺序闯关、宠物养成）**。
核心闭环：日历排期 → 顺序闯关 → 完课得能量 → 喂养宠物 → 周末奖励。
解决家长痛点：视频杂乱、孩子难坚持、缺约束；抓孩子心理：成就感、即时反馈、收集养成。

## 明确要克制的
- 不要功能堆叠。现有 PRD V2.0 里的 AI PK、卡牌合成、收藏馆、兴趣画像、家长洞察报告属于偏离初心的膨胀，优先级最低/建议冻结。
- 不要用「全部课程包平铺展示」制造混乱；不要用 8 个学科平铺。
- 宠物不做「不学习就生病」式负罪感设计（正向陪伴）。

## 2026-11-09 讨论形成的设计方向（待确认后落地）
- 课程包三层：`学科（语文 / 数学 / 英语 / 探索）→ 体系（课程包，一条有序闯关线）→ 讲次`。「其他」改称「探索」。
- **孩子端首页只有「今日航线」2–3 关**；完整三层树只存在于家长排期后台（拖拽日历时按 学科→体系 筛选，拖讲次进日期槽）。
- **顺序锁作用域仅体系内**，不跨体系、不跨学科，否则会死锁。跨体系顺序由家长日历决定。
- 宠物＝**一只固定底座（孩子选/命名，永不换）+ 四维属性部件**：语文→文心/书卷纹/护盾，数学→算力/齿轮甲/破防，英语→共鸣/星轨翼/连击，探索→灵感/稀有掉落/剧情。属性决定外形部件、技能、特效，不决定「是谁」。最高属性给动态称号与光效。
- **只做均衡激励，不做偏科惩罚**：最弱属性喂养 ×1.5；四维之和定星级，进化门槛用木桶（三条达标 + 短板不低于下限，不要求四维全满）。
- 科普/探索不参与主战力，避免变成第四个必刷科目。

## 设计稿交付尺寸（2026-11-12 定）
给 iPad 端的设计稿，**画板必须 4:3**，不要再给 16:9。
- 主稿：**1366 × 1024 @1x**（横屏），导出 @2x = 2732 × 2048。对应 iPad Pro 12.9″。
- 覆盖机型：12.9″ 1366×1024 / 11″·Air 1194×834 / 10.9″ 1180×820 / 10.2″ 1080×810，横屏全是 4:3，等比缩放不变形。
- 竖屏版另出：1024 × 1366。
- 规范：安全边距四周 32pt（@2x 64px，避圆角与状态栏）；底部导航高 72–80pt 并留 Home 指示条空间；最小点击区 44×44pt；卡片圆角 24–28pt。
- 交付时标注哪些区块「固定高」、哪些「可拉伸」，否则开发只能照像素硬摆，换机型就崩。
- 参考反例：`ipad-design/` 最初用 2848×1600 和 2730×1536（16:9），塞进 4:3 画布底部空 25%，已用分区纵向缩放补救。
